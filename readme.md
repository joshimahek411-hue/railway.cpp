# 🚆 Railway Reservation System in C++

## 📌 About Project


I created this project to understand and practice basic C++ concepts and Object-Oriented Programming (OOP).

This project allows users to add new train records, display all train records, and search for a train using its train number.

It is a menu-driven program, so users can select different options according to their needs.

## 🎯 Project Features

This project has the following features:

1. **Add New Train Record** – User can add new train details like train number, train name, source, destination, and train time.

2. **Display All Train Records** – User can display all the train records that have been added.

3. **Search Train by Number** – User can search for a particular train by entering its train number.

4. **Exit** – User can exit the program.

## 🛠️ Technologies Used

- C++ Programming Language
- iostream Header File
- cstring Header File
- Object-Oriented Programming (OOP)

## 📚 C++ Concepts Used

In this project, I have used the following C++ concepts:

- **Class:** Used to create Train and RailwaySystem classes.
- **Object:** Used to access class members.
- **Constructor:** Used to initialize the variables.
- **Destructor:** Used to decrease the train count when an object is destroyed.
- **Static Variable:** Used to maintain the train count.
- **Setter Functions:** Used to set train details.
- **Getter Functions:** Used to get train details.
- **Array of Objects:** Used to store multiple train records.
- **Functions:** Used to perform different operations.
- **Do-While Loop:** Used to display the menu repeatedly.
- **Switch Statement:** Used to perform operations according to user choice.
- **If-Else Statement:** Used to check different conditions.

## ⚙️ How to Run the Project

Follow these simple steps to run the project:

1. Download or copy the project code.
2. Open any C++ compiler or IDE.
3. Create a new C++ file.
4. Paste the project code into the file.
5. Save the file with `.cpp` extension.
6. Compile and run the program.
7. Select an option from the menu.
